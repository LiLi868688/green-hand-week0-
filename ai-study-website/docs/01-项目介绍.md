# 项目介绍

## 一、项目目标

初学者往往在课程、代码编辑器、习题和笔记之间切换，学完概念后也缺少动手实践。本项目将这些活动整合为一个个人学习网站，帮助学习者从读懂概念走向编写和检验代码。

## 二、用户与页面

面向从零开始学习Python、数学和AI的个人用户。主要页面是课程目录、学习路线、课程详情、练习工坊、项目实践、笔记、复习、设置和参考资料。

核心流程：选择课程 → 阅读生活例子与图解 → 理解手算与逐行代码 → 修改示例并运行 → 完成练习 → 通过分步项目整合知识 → 保存笔记与学习记录。

## 三、主要实现

1. 课程与界面分离：结构化课程数据由内容脚本生成，界面按课程编号呈现。
2. 真实代码执行：编辑器把代码发给独立Web Worker，由Pyodide执行并返回输出或错误；停止按钮终止Worker，30秒超时防止无限循环长时间占用页面。
3. 练习判题：函数题对多个参数组合调用用户函数，比较嵌套返回值、浮点误差和输入是否被修改。不同正确写法均可通过，不用代码文本匹配评分。
4. 学习记录：localStorage按固定键保存课程完成、代码、笔记、收藏与练习提交；JSON导出导入支持手动备份迁移。
5. 渐进教学：先问题与例子，后术语、公式、逐行代码，再提供分级提示和参考答案。

## 四、设计取舍

单人、本机优先，因此无需账号系统、社区或数据库服务。使用标准库服务和静态文件减少安装成本；在浏览器执行Python也避免在应用服务器直接运行任意用户代码。

代价是数据仅属于当前浏览器，尚无自动跨设备同步；部分Python库和系统操作不受浏览器支持。课程执行过程中的检查点是预录示例，用户修改后的结果以实际运行区为准。

## 五、规模与边界

112节课、30模块、175题、19项目，包含112张本地图解。内容广度覆盖Python及AI入门，但不代表完整高校课程深度。AI聊天、GPU训练、联网API和自动云同步未实现，不作为已完成功能展示。
