# AI辅助与参考来源

本项目使用AI辅助需求梳理、教学内容编排、前端与运行代码编写、练习设计及文档整理。提交者提出学习目标和界面要求，通过多轮反馈调整，并在AI辅助下完成检查。请按学校课程规定说明AI使用情况并保留真实贡献说明。

课程、练习和项目为教学整理与原创迁移设计，并非高校官方题库、官方答案或课程认证。

- Harvard CS50P： https://cs50.harvard.edu/python/psets/
- MIT 6.0001： https://ocw.mit.edu/courses/6-0001-introduction-to-computer-science-and-programming-in-python-fall-2016/pages/assignments/
- Think Python： https://greenteapress.com/wp/think-python-3rd-edition/
- Dive into Deep Learning： https://d2l.ai/
- ISLP： https://www.statlearning.com/resources-python
- Python文档： https://docs.python.org/zh-cn/3/tutorial/
- 菜鸟教程： https://www.runoob.com/python3/python3-tutorial.html

各课程另提供官方文档及原始论文入口。第三方运行环境Pyodide随项目附带，其许可文本保存在dist/python/LICENSE，保留其原始版权与许可声明。
