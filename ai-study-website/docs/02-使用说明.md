# 启动与使用说明

## 环境

桌面浏览器及Python 3。网页使用现代浏览器的Web Worker和WebAssembly，建议Chrome、Edge或Safari近期版本。无需安装前端依赖，浏览器Python运行文件已附带。

## 通用启动方式（优先推荐）

1. 解压整个项目，不要单独打开index.html。
2. 在项目根目录打开终端。
3. macOS/Linux执行 `python3 server.py`；Windows执行 `py -3 server.py` 或 `python server.py`。
4. 打开 http://127.0.0.1:5278/ 。保持终端运行，按Ctrl+C可停止。

## 双击启动

Mac：双击“打开AI学习.command”；若系统未允许执行，请使用上方通用命令启动。
Windows：双击“打开AI学习.cmd”；此后台启动器寻找用户目录安装的Python运行时，找不到时改用通用命令。项目未附带Windows Python安装程序。

## 课堂演示顺序

课程目录 → 任意课程 → 编辑示例运行 → 练习 → 提交测试 → 查看提示 → 项目 → 笔记或设置备份。

函数题要用return返回结果，print只用于观察输出。代码运行在浏览器虚拟环境，无法直接访问用户桌面文件。停止和超时均会终止本次执行。

## 保存与隐私

笔记、进度和代码保存在当前浏览器，刷新可恢复。不同浏览器或设备的数据不自动共享。在设置中导出JSON，再到另一浏览器导入。提交包不含开发者的个人浏览器记录、API密钥、日志和云端账号配置。

## 常见问题

- 无法连接：先运行server.py，再访问本机地址；重启电脑后需重新启动服务。
- 端口被占用：已有正确服务可直接使用；其他程序占用5278时，请关闭占用程序再启动。
- 首次执行较慢：浏览器需要加载本地Python运行环境，页面保留30秒超时保护。
- 修改代码后没有输出：函数定义本身不输出内容，在末尾加print调用，或点击提交进行测试。
- 老师电脑打不开127.0.0.1：该地址指向老师自己的电脑，必须先解压并启动项目。
